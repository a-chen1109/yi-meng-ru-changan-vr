# 一梦入长安 · 千灯贺芳辰 — 360° VR Starter

这是一个可运行的手机优先 360° 全景原型，保留原生日页的暖金灯火、月色、诗词与祝福风格。

## 目录结构

```text
yi-meng-ru-changan-vr/
├── index.html                 # 原生日页 + 进入 VR 的入口
├── vr.html                    # 360° 全景体验
├── vr.css                     # VR 页面样式与手机适配
├── vr.js                      # 场景切换、热点、祝福、陀螺仪与音乐逻辑
└── assets/
    ├── panoramas/              # 当前页面使用的四张 2:1 全景图
    │   ├── scene1_gate.png     # 入梦长安
    │   ├── scene2_gate.png     # 灯映星河
    │   ├── scene3.png          # 月下寄愿
    │   └── scene4.png          # 烟火贺辰
    ├── audio/
    │   └── README.txt          # 请将有权使用的歌曲音频放在此目录
    └── ui/                     # 预留给后续图标素材
```

## 运行方式

推荐通过本地 HTTP 服务运行，而不是直接双击 `vr.html`：

1. 安装 Python 3（如电脑已有 Python 可跳过）。
2. 在本目录打开终端并运行：

   ```bash
   python -m http.server 8000
   ```
3. 电脑访问 `http://localhost:8000`。
4. 手机测试时，电脑和手机连同一 Wi-Fi，访问电脑的局域网 IP，例如 `http://192.168.1.20:8000`。

注意：陀螺仪在 iOS Safari 等环境可能要求 HTTPS 或显式授权；线上部署建议使用支持 HTTPS 的静态托管服务。触屏滑动环视和点击热点不依赖陀螺仪。

## 音乐接入

将你有权使用的音频文件放到 `assets/audio/`，文件名为：

`ruo-ni-de-shijie-mei-you-nuan-yang.mp3`

也可以在 VR 页面点击「选择音乐」从当前设备载入音频预览。选择本地文件只对当前设备与当前会话有效，不会自动上传到网站。请确认你有权在网页中使用该录音。

## 这版已经包含

- 四个全景场景：入梦长安、灯映星河、月下寄愿、烟火贺辰
- 手机单指拖动环视、Pointer Events 点击热点
- 五盏祝福花灯、诗词弹窗、放灯祝福动画
- 场景切换导航，作为空间热点的可访问备用入口

## 重要说明

VR 页面已接入 `assets/panoramas/` 中的四张 PNG 图片，按上面的顺序对应四个场景。打开 `vr.html`，点击「入梦长安」后可拖动环视，并通过底部按钮切换图片。首页 `index.html` 的「进入 360° 长安」也会打开该体验。

图片以 2:1 等距柱状投影（equirectangular）方式铺在全景球面上，不是完整的自由行走 3D 城市。后续替换图片时，保持相同文件名即可；画面接缝和上下极点的自然程度取决于原图的全景制作质量。

如果将来要做完整 3D 自由行走或头显手部追踪，需要另行添加 3D 模型（GLB/GLTF）并针对目标设备测试 WebXR 输入能力。

## 夜游界面

场景标题位于左侧，底部依次为「入梦、流光、寄愿、贺辰」。右上角音乐按钮用于播放或暂停，设置中可选择本地音乐和开启陀螺仪。首次进入的操作提示会在约 6.5 秒后淡出。

最后的生辰祝福称呼可在 `vr.js` 的 `friendName` 中修改。

## 背景音乐

首页和全景页默认使用 `assets/music/视频转音频20261018002453.mp3`，预加载并循环播放。页面打开时会立即尝试播放；如果浏览器拦截有声自动播放，则在用户第一次点击页面或点击「入梦长安」时自动重试。右上角音乐图标用于暂停或继续。

设置中的 QQ 音乐和「选择音乐」仍作为备用方式。切换到 QQ 音乐或临时选择本地文件时，会暂停当前默认音乐，避免声音重叠。

最新全景页面为 `vr.html`，相关样式和交互分别为 `vr.css`、`vr.js`。`index.html` 是保留的生日首页，因此直接打开首页时仍会先看到原首页设计；点击首页「进入 360° 长安」进入新版。修改直接保存在这些文件中，没有另生成一个“最新版”文件。

## 本机打开与自动播放限制

双击 `打开长安网页.cmd`，将自动启动本机 HTTP 服务并在默认浏览器打开最新版。浏览期间保留启动窗口，关闭该窗口即停止此服务。默认使用 8765 端口；端口占用时会选择另一个可用端口，以启动窗口打印的地址为准。可把地址栏中的完整网址复制到 Chrome、Edge 等其他浏览器。启动脚本使用此电脑已有的 Python 3。

请勿直接通过 `file:///.../vr.html` 查看全景。文件模式下页面会显示启动入口说明；在 HTTP 模式下，如全景引擎未能加载，会提示检查网络后刷新。当前全景引擎仍通过 aframe.io 在线加载。

现代浏览器可能拦截访客首次打开页面时的有声自动播放，因此无法保证所有设备都能在零操作的情况下出声。当前实现会先自动尝试，并在第一次用户互动时重试；「入梦长安」按钮是最稳定的播放触发点。
